# AI Job Application Tracker 🚀

A full-stack **MERN** application that helps users track job applications, manage notes, upload resumes, and analyze resume–job fit using **AI**

## Deploy: Render API + Vercel frontend

Use Node.js 24 for both projects. MongoDB is hosted separately (for example, MongoDB Atlas).
The repository includes a Render Blueprint and Vercel configuration.

### 1. Deploy the API on Render

1. Push the repository to GitHub. In Render, create a **Blueprint** from the repository;
   Render reads the root `render.yaml`. For an existing web service, select the Node runtime,
   root directory `backend`, build command `npm ci --omit=dev`, start command `npm start`,
   and health check path `/health`.
2. Provide the environment variables below. The Blueprint generates `JWT_SECRET` and supplies
   `NODE_ENV`, `NODE_VERSION`, and `JWT_EXPIRES_IN` automatically. For an existing service,
   add those variables manually as well.

| Render variable | Value |
| --- | --- |
| `MONGO_URI` | MongoDB connection string including the database name |
| `JWT_SECRET` | A long random secret; generated by the Blueprint |
| `JWT_EXPIRES_IN` | `7d` |
| `CLIENT_URL` | Your exact Vercel frontend URL, e.g. `https://your-project.vercel.app` |
| `GEMINI_API_KEY` | Your Gemini API key for resume analysis |
| `NODE_ENV` | `production` |
| `NODE_VERSION` | `24.13.1` |

3. Allow the Render service's outbound IPs in your MongoDB provider's network access settings.
   Use the outbound IPs shown for your service in Render.
4. Deploy and open `https://YOUR-API.onrender.com/health`; expect `{"status":"OK"}`.
   Render supplies `PORT`; the server already listens on `0.0.0.0`.

`CLIENT_URL` accepts comma-separated URLs for a production domain, custom domains, and
specific preview deployments. Trailing slashes are normalized. Preview URLs must be added
explicitly; other Vercel projects are not automatically trusted. If the Vercel URL is not
known yet, finish the frontend setup below, then update `CLIENT_URL` and restart the API.

### 2. Deploy React on Vercel

1. Import the same repository in Vercel and select **Root Directory: `frontend`**.
2. Use the **Create React App** preset and Node.js **24.x**. The included `frontend/vercel.json`
   sets install command `npm ci`, build command `npm run build`, output directory `build`,
   and a fallback to `index.html` for React routes such as `/signup` and `/dashboard`.
3. Set `REACT_APP_API_URL=https://YOUR-API.onrender.com` in Vercel's environment settings.
   Use the API origin only, without `/api/v1`. Set it for Production and for Preview if used.
   The build fails with a clear message if this variable is missing or malformed.
4. Deploy, then set Render's `CLIENT_URL` to the actual Vercel URL. After changing
   `REACT_APP_API_URL`, redeploy the frontend because React embeds it at build time.
5. Check signup, login, and a page refresh on `/signup`. The browser's registration request
   should target `https://YOUR-API.onrender.com/api/v1/register`.

Keep database credentials, JWT secrets, and Gemini keys on Render only. All `REACT_APP_*`
variables are public. Example local configuration is in `backend/.env.example` and
`frontend/.env.example`; copy each to `.env` in the same directory for local development.

### Resume file storage

The Blueprint selects Render's free plan, whose local filesystem is ephemeral. Uploaded
resume files are lost on restarts or deploys; parsed text and resume metadata remain in
MongoDB. To retain original files, use a paid Render service with a persistent disk mounted
at `/var/data` and set `UPLOAD_DIR=/var/data/resumes`, or integrate object storage.
The app creates the upload directory automatically. Existing files are not migrated.

Platform references: [Render Express deployment](https://render.com/docs/deploy-node-express-app),
[Render Blueprint configuration](https://render.com/docs/blueprint-spec),
[Render persistent disks](https://render.com/docs/disks), and
[Vercel project configuration](https://vercel.com/docs/project-configuration/vercel-json).

## ✨ Features

### Authentication & Security
- JWT-based authentication
- Protected routes on frontend & backend
- Auto-login using stored token

### Job Application Management
- Create, update, and delete job applications
- Track application status (Applied, Interview, Offer, Rejected)
- Add notes for each job application

### Resume Management & AI Analysis
- Upload resumes (PDF)
- Parse resume content
- Analyze resume against job description using AI
- AI-generated match score
- Strengths, missing skills, and improvement suggestions

### Dashboard & Analytics
- Total applications count
- Status-wise breakdown
- Average AI match score
- Monthly application trend
- Top missing skills across applications
- Recent applications widget
